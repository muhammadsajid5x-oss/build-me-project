# Testing Standard

## Purpose

Ensure software quality through automated testing.

## Every Feature Requires

```text
Unit Test
      +
Integration Test
      +
End-to-End Test
```

## Testing Tools

- Jest
- Playwright
- Cypress

## Rules

- Write unit tests for business logic.
- Verify integrations between services.
- Validate complete user journeys with E2E tests.
- Tests must pass before merging into the develop branch.
