# Developer Onboarding

## Step 1

Clone Repository

```bash
git clone <repository-url>
```

---

## Step 2

Install Dependencies

```bash
pnpm install
```

---

## Step 3

Configure Environment

Create a `.env` file and add:

```
DATABASE_URL=

SUPABASE_URL=

SUPABASE_KEY=

API_URL=
```

---

## Step 4

Run Development

```bash
pnpm dev
```

---

## Step 5

Run Tests

```bash
pnpm test
```

---

## Step 6

Create Feature Branch

```bash
git checkout -b feature/feature-name
```

---

## Developer Workflow

Clone Repository

↓

Install Dependencies

↓

Configure Environment

↓

Run Project

↓

Run Tests

↓

Create Feature Branch

↓

Start Development
